### What I learned

I used flexbox to align the card in the center. I used pseudo class to generate blueprint for later use.

```
:root {
  --green: hsl(75, 94%, 57%);
  --white: hsl(0, 0%, 100%);
  --bg-color: hsl(0, 0%, 8%);
  --mid-grey: hsl(0, 0%, 12%);
  --grey: hsl(0, 0%, 20%);
}
```

I also set margin, padding to zero and for box-sizing, I use border-box.
